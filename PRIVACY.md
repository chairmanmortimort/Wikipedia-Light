# Privacy

The Wikipedia tool contacts the public Wikipedia API (wikipedia.org) to search and fetch article text. Your queries and IP address reach Wikimedia under their normal request handling. There is no account, no analytics, and no data stored on any server we operate; nothing is kept on the device beyond the current session.

## Permissions

The tool declares its permissions in `tool/lighttool.toml`. The merged APK also inherits Android
permissions and components from the current Light SDK dependency graph.

## Analytics and accounts

None. There is no analytics integration, no advertising, no tracking, and no account. Nothing is
collected or shared by us.
